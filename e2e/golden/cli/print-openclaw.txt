Manual setup for openclaw. Put this in <HOME>/.openclaw/openclaw.json
(If the folder or file is missing, create it. If the file exists, add the context-mode entry
and keep the rest. These paths are for this machine.)

{
  "mcp": {
    "servers": {
      "context-mode": {
        "command": "<NODE>",
        "args": [
          "<PKG>/server.mjs",
          "--agent",
          "openclaw"
        ]
      }
    }
  }
}

Hooks: add the hook block from `context-mode setup --print openclaw --json` to <HOME>/.openclaw/extensions/context-mode/index.ts
(keep your own entries).

Hooks: add the hook block from `context-mode setup --print openclaw --json` to <HOME>/.openclaw/extensions/context-mode/openclaw.plugin.json
(keep your own entries).

Then restart the agent and check it: context-mode doctor --agents openclaw
