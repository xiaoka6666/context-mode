Manual setup for openclaw. Put this in <HOME>/.openclaw/openclaw.json
(If the folder or file is missing, create it. If the file exists, add the context-mode entry
and keep the rest. These paths are for this machine.)

{
  "mcp": {
    "servers": {
      "context-mode": {
        "command": "<NODE>",
        "args": [
          "<PKG>/server.mjs",
          "--agent",
          "openclaw"
        ]
      }
    }
  }
}

Then restart the agent and check it: context-mode doctor --agents openclaw
